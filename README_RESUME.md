# Страница Резюме - Обновленная версия

Теперь страница резюме полностью соответствует дизайну сайта и скачивает готовый PDF файл!

## ✨ Что изменилось

### 🎨 Новый дизайн

- **Полностью соответствует стилю сайта** - темная тема, прозрачные карточки, градиенты
- **Современная сетка** - основной контент + боковая панель
- **Адаптивный дизайн** - отлично выглядит на всех устройствах
- **Гармоничные цвета** - использует цветовую схему сайта (#667eea, #b8c1ec, etc.)

### 📄 Скачивание PDF

- **Готовый PDF файл** - замените `public/Marta_Hayrapetyan_Resume.pdf` на свой файл
- **Простая загрузка** - кнопка создает ссылку для скачивания
- **Без генерации** - нет зависимости от html2pdf.js

## 🔄 Как заменить PDF файл

### Шаг 1: Подготовьте свой PDF

Создайте профессиональное резюме в PDF формате с:

- Вашим именем в названии файла
- Высоким качеством печати
- Оптимальным размером (A4)

### Шаг 2: Замените файл

1. Перейдите в папку `public/`
2. Замените файл `Marta_Hayrapetyan_Resume.pdf` на свой
3. Переименуйте файл в `Marta_Hayrapetyan_Resume.pdf` (или измените код)

### Шаг 3: Обновите код (опционально)

Если хотите другое имя файла, измените в `ResumePage/index.tsx`:

```typescript
link.href = "/Your_Resume_Name.pdf";
link.download = "Your_Resume_Name.pdf";
```
